# Student Dropout Prediction & Academic Success System

Hackathon Project Starter Repository.

## Project Structure
- `data/`: Data storage (gitignored).
- `ml/`: Model notebooks and source training code.
- `backend/`: FastAPI application server.
- `frontend/`: Dashboard visual code templates.
- `genai/`: LLM prompt templates and recommendation service logic.
- `docs/`: Design and feature documentation.
