# Feature Dictionary

This document defines the fields in the student records.

## Academic Features
- `grade_sem1`: Grade average in the 1st semester.
- `grade_sem2`: Grade average in the 2nd semester.
- `units_enrolled_sem1`/`units_enrolled_sem2`: Number of credits enrolled.
- `units_approved_sem1`/`units_approved_sem2`: Number of credits successfully completed.

## Demographic Features
- `gender`: Gender code (0: Female, 1: Male).
- `age_at_enrollment`: Student age at start of course.

## Socio-economic Features
- `scholarship_holder`: Whether the student holds a scholarship (0: No, 1: Yes).
- `debtor`: Whether the student has outstanding debt (0: No, 1: Yes).
- `tuition_fees_up_to_date`: Fees status (0: No, 1: Yes).
